关于
糖包是什么

糖包是一款本地运行的 AI 助手桌面端（基于 Electron）。它把多种 AI 能力整合到左侧导航的「模块」里，数据保存在你本机，不强制上传云端。

模块一览
💬
糖包 · 聊天
多轮对话。顶部可切换模型、开启「深度思考」与「联网搜索」，对话可通过顶部 ⋯ 菜单导出或复制为 Markdown。
🎨
糖绘 · 图像
输入文字描述生成图片。
📖
糖读 · 文档
上传文档后，可对内容进行总结、提取要点、翻译、生成提纲等分析。
🤖
糖创 · 智能体
面向任务型智能体、工具和工作流。可使用预设或自建智能体，配置系统提示词、语气、模型与多步骤执行；角色卡和沉浸式会话请使用糖馆。
🏯
糖馆 · 角色会话
角色卡与沉浸式角色会话。角色设定、开场白、快捷 starter 和专属世界书只作用于当前角色，不会自动出现在糖创中。
⚡
糖码 · 本地智能体
本地运行的 agentic 编码助手。在限定工作目录内自主调用工具——读写文件、执行命令、运行 git、联网检索；以「项目 + 多会话」组织，每步受权限管控。
🔌
自定义模块
在设置 → 自定义模块中，通过 iframe / webview 嵌入你自己的应用或网页，与内置模块并排使用。
快速上手
  1. 打开左下角齿轮 →「配置 / 账户」，新增一个账户，填写 API Base URL、API Key 与模型。
  2. 在「配置」中选择该账户作为默认（或按需为各模块单独指定）。
  3. 从左侧导航切换模块，直接开始对话或创作。
  4. 在「模块」面板里可开关内置模块、或添加自定义网页模块。
  5. 使用「糖码」时，先新建项目并配置工作目录与权限，再开始编码。
配置
配置

在「配置」先选模块（默认 / 糖包 / 糖绘 / 糖读），再到「账户」新增账户：API Base URL、API Key、模型列表。可设一个默认账户，也允许各模块独立账户。

⚠️ 密钥保存在本机系统安全存储中，不会上传到糖包服务器；导出配置不会包含密钥。

自定义模块

在「模块」面板底部添加自定义模块：填写名称与网页 URL（http/https），它会以 iframe 嵌入并出现在左侧导航。切换模块不会重载网页；若页面需要刷新，可点顶栏的刷新按钮手动刷新。

外观与数据

「外观」可切换浅色 / 深色 / 跟随系统，自定义强调色与界面圆角，修改即时生效并在刷新后保持。

「数据」可导出 / 导入配置（账户、智能体、工作流、提示词、外观、模块开关）；旧版模板字段仅为兼容旧数据而保留。导入会覆盖现有设置。

权限
糖码项目权限

糖码以「项目」为单位管理权限，每个项目可设置：

  • 自动执行（auto）：开启后工具调用无需逐个确认；关闭则需你每次审批。
  • 需审批工具（approveTools）：列出必须人工确认后才执行的工具。
  • 命令白名单（cmdWhitelist）：仅允许执行白名单内的命令，未列出的命令将被拦截。

所有工具调用都以本地安全围栏（safePath）为硬约束，越权操作会被拒绝。

常见问题
  • 请求被 CORS 拦截？浏览器直连第三方 API 可能受跨域限制。请将 Base URL 指向支持跨域的端点，或自建本地代理。
  • 怎么换模型？ 聊天模块顶部点模型按钮切换；也可在「配置」里为模块指定默认模型。
  • 导出配置包含什么？ 导出文件含对话、模块设置与密钥引用，但 不含 API Key 明文（密钥由系统密钥库加密保管）。请勿将导出文件分享给他人。
  • 自定义模块打不开？ 请确认 URL 为 http/https 且目标站点允许被 iframe 嵌入（部分站点设置了 X-Frame-Options 会拒绝）。
隐私提示

⚠️ 你的对话与文档保存在本机；API Key 由系统密钥库（Windows DPAPI / macOS Keychain / Linux libsecret）加密保管，明文不再写入任何本地文件。糖包不会主动上传你的数据，请自行负责本地备份。
