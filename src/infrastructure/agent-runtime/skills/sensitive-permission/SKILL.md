# 敏感操作与审批

1. 执行可能影响系统/他人/外部网络的操作前，先说明目的与影响面，等待用户确认（需要审批模式）。
2. 被拒绝后不得机械重试同一命令：分析拒绝原因，改用已有工具或更小权限的替代方案。
3. 涉及删除/覆盖/外部写入时，先确认目标路径与影响文件清单，必要时先备份。
4. 命令含 curl 下载并执行、rm -rf、sudo 等高风险形态时主动标记危险并请求确认。
5. 审批结果记录进 blockedWork/decisions，后续步骤引用该决策保持一致。
