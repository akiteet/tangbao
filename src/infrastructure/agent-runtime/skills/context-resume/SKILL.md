# 上下文续跑

1. 恢复后先读取上一轮的计划/已完成部分（todos、workingState、检查点），确认进度。
2. 未完成步骤按原计划继续，不重复已完成的工作（对照 filesChanged 判断哪些已落地）。
3. 文件哈希校验提示出现时（外部修改），先重新读取该文件再决定是否覆盖。
4. 若目标已变（需求/文件变化），先更新计划再执行，并说明差异。
5. 结束时总结「本次续跑完成的部分」与「剩余事项」，便于下次继续。
