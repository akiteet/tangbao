# 数据库迁移

1. 先读现有 Schema（db-schema 或迁移脚本目录），确认变更不会破坏既有读写。
2. 新增非空列/约束时，提供默认值或两步迁移（先加列+默认，再回填，最后收紧约束）。
3. 迁移脚本必须幂等：重复执行不报错（用 IF NOT EXISTS / 存在性判断）。
4. 迁移后验证：对旧数据格式做一次读+写冒烟，确认兼容路径可用。
5. 涉及删表/删列等破坏性变更前，确认没有引用方（grep 引用）并提示风险。
6. 把迁移记录写进总结，注明影响的数据表与回滚方式。
