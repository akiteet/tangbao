# 糖包 v1.0.8 发布说明

> 发布日：2026-08-05 ｜ 仓库：github.com/akiteet/tangbao

## 本次版本主要更新（体验优化专项）

### 1. 模块功能增强
- **智能体语气生效**：糖创智能体配置的「语气」（专业 / 亲切 / 幽默等）此前为无效字段，现真正注入系统提示（"请用『XX』的语气回复用户"）；智能体指定的模型不在当前账户时给出明确提示并回退默认。
- **糖绘高级参数分层**：常用参数（提示词 / 参考图 / 比例 / 数量 / 模型）始终显示；「高级参数」折叠区提供 **Seed、Guidance、负面提示词、输出格式、质量、模型专属参数（JSON 透传）**——按供应商自动映射（OpenAI 兼容字段 / 火山与 SD 的 cfg_scale、negative_prompt），参数随历史保存、失败重试原样带参。
- **糖绘生成队列**：多任务串行排队（并发 1），支持取消与失败重试，状态一目了然。
- **糖绘提示词预设**：一键保存 / 点选填入 / 删除常用提示词；历史图片支持「对比」2 张并排对照。
- **聊天编辑消息**：可编辑上一条用户消息重新生成；「重新生成」的回复支持 **1/2、2/3 版本切换**（同一问题多答案对比，上限 5 版），按钮位于「重新生成」与「删除」之间。
- **对话全文搜索**：侧栏搜索升级为标题 + 消息内容（含深度思考）匹配，命中对话显示「N 条命中」徽标。
- **糖读检索升级**：结构化分块 + 轻量 BM25 检索（替代词频）；「提问范围」支持当前 / 全部文档跨文档融合问答，引用带来源文档名并可跳转定位；低相关查询给出提示。
- **工作流增强**：运行历史持久化（独立 SQLite 表 + 历史面板）；每步可选模型、失败策略（继续 / 停止 / 重试×2）、输入变量 {{var}} 收集替换。
- **账户与模型拖拽排序**：账户列表与账户内模型列表支持自由拖拽排序（替代原上下箭头）；账户编辑改为弹窗，点击「添加 / 编辑」才弹出。

### 2. 界面与交互统一（视觉专项）
- **糖读全新布局**：左侧可折叠文档边栏（上传 / 文档列表 / 分析 / 大纲）+ 全屏聊天式问答（复用聊天视觉：头像 / 气泡 / 复制 / 引用卡片）；文档预览改为右侧抽屉，点击文档 / 大纲 / 引用时弹出并自动定位；空状态居中引导。
- **糖绘 / 糖创卡片化**：与糖读统一为「大卡片框 + 区域子卡」布局（shell / sec 两级），元素成组有边界。
- **顶栏减负**：模型选择、置顶浮窗开关、上下文用量条（缩为小角标）全部移入底部输入区，顶栏只留标题与菜单。
- **尺寸体系统一**：间距收敛到 4 / 8 / 12 / 16 / 24 / 32 / 48 刻度；圆角新增 `--radius-lg` / `--radius-pill`，全部接入「设置 → 外观」圆角滑杆（大卡片 / 气泡随滑杆联动，胶囊恒定全圆）。
- **细节美化**：编辑提示条圆角卡片化；糖读「提问范围」不再换行；分析按钮单行均分；边栏折叠修复（折叠后保留展开按钮）。

### 3. 问题修复
- 糖读边栏折叠后无法重新展开（折叠态把展开按钮一并隐藏）。
- 糖读「提问范围」下拉不必要换行。
- 智能体 tone 死字段、模型静默回退。

## 升级提示
- 本版本沿用 SQLite 数据存储（v1.0.7 引入），升级不丢聊天记录；图片已迁移为文件存储。
- 如遇任何异常，可在「设置 → 数据」使用完整数据备份导出后再操作。
