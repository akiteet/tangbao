# 糖包 v1.2.0

> 本地优先、私密可控的 AI 工作空间。

v1.2.0 是糖包的一次重要能力升级：工作区从单一对话工具，扩展为覆盖开发、创作、文档、角色与工具协作的桌面环境；同时完成底层运行时、数据持久化与安全边界的系统性加固。

## 重点更新

### 多角色群聊

糖馆支持创建由多个角色组成的独立群聊：

- 角色按成员顺序轮流发言，每轮可由角色明确选择沉默；
- 每条发言保留成员归属，群聊上下文会清楚区分发言者；
- 支持只重新生成指定成员，不重复运行整个群聊；
- 重新生成时保留后续成员已经产生的内容；
- 流式生成期间头像会跟随当前发言成员；
- 角色会话、群聊会话和普通聊天相互隔离，跨角色打开会话时归属保持一致；
- 支持角色卡排序、收藏置顶、自定义头像与已删除角色会话清理。

### MCP 工具扩展

糖码支持接入标准 Model Context Protocol（MCP）服务器，将本地或远程工具纳入 AI 编程工作流：

- 支持 `stdio` 本地进程与 HTTP 远程端点；
- 在设置中编辑 server 配置，并使用「测试连接」查看工具清单；
- 工具以 `mcp__服务id__工具名` 的形式提供给糖码；
- MCP 工具调用默认进入审批流程；Plan 模式不会执行 MCP 工具；
- 支持项目根目录 `.mcp.json`，项目级同名 server 覆盖全局配置；
- 连接默认超时 30 秒，工具调用默认超时 60 秒，单次输出超过 200KB 会截断；
- 仅启用的 server 会被连接和注入工具列表。

示例：

```json
[
  {
    "id": "filesystem",
    "name": "文件系统",
    "transport": "stdio",
    "command": "npx",
    "args": ["-y", "@modelcontextprotocol/server-filesystem", "D:/workspace"],
    "enabled": true
  }
]
```

### 应用内更新

设置 → 帮助新增应用更新入口：检查新版本、下载更新，并在准备完成后重启安装。更新流程仅在打包版本启用，开发环境会显示明确的状态说明。

## 工作区与效率

- 新增用量统计仪表盘，按模型查看调用次数、成功数、输入/输出/思考 token 与平均延迟，支持最近 7 天、30 天和全部范围；
- 完善快捷键：Ctrl/Cmd+N 新建会话、Ctrl/Cmd+F 本地搜索、Ctrl/Cmd+K 命令面板、Ctrl/Cmd+`,` 打开设置、Ctrl/Cmd+1~8 切换模块；全局浮窗快捷键默认为 Ctrl+Shift+F；
- 新增键盘界面缩放：Ctrl/Cmd+= 放大、Ctrl/Cmd+- 缩小、Ctrl/Cmd+0 重置，也支持 Ctrl+滚轮；
- 上下文压缩触发比例、保留消息数、摘要长度、糖馆检索预算与条数均可配置；
- 全文检索结果改为展示命中位置附近的片段，减少长文本干扰；
- Skills 支持标准 `SKILL.md` 机制，可从约定目录加载、显式调用、启停和隔离处理；
- 支持多根工作区，可按任务限定文件写入范围；
- 运行记录支持检查点、分页浏览、全文检索与中断恢复。

## 浮窗与窗口体验

- 浮窗装配支持十项独立开关，默认保持简洁；
- 每次启动应用时浮窗默认关闭，不再自动恢复上次的显示状态；位置、尺寸、透明度与置顶设置仍会保留；
- 托盘、主窗口入口与全局快捷键仍可随时打开浮窗；
- 自定义模块支持独立小窗；同一模块可多开；子窗口支持正常最小化、最大化和任务栏管理；
- 三个糖馆 tab 统一为等宽布局，操作区贴底，当前会话与所属角色高亮保持一致；
- 角色编辑器支持头像上传、预览与移除。

## 视觉与交互

- 完成新一轮中性、克制的界面系统整理，统一控件、间距、字号、滚动条、卡片和弹窗规范；
- 更新糖包 logo、应用图标、托盘图标与启动闪屏；
- 更新卡片显示当前版本；
- 输入工具按钮补充按压、禁用和焦点状态；
- 暗色主题、窄窗口、长列表和模块切换体验进一步收敛；
- 联网搜索改用 Electron 网络栈，自动继承系统代理，并将失败原因明确反馈给用户。

## 数据、隐私与安全

- Electron 升级至 34.5.8，better-sqlite3 升级至 12.11.1；安装版的本地 SQLite 能力完整可用，原生模块已随应用正确打包并通过 ABI 验证；
- 首次使用新版安装包时会初始化本地 `tangbao.db`，并从既有配置同步数据；用量统计自本版正常运行后开始累计；
- API Key 由操作系统密钥库保护，仅主进程处理明文；
- 会话、设置、附件与本地索引保存在设备上的 SQLite 和文件仓中；
- Skills 默认阻断网络出站，只有明确允许的配置才开放网络；
- 工具调用、文件写入、命令执行和 MCP 调用沿用统一权限与审批边界；
- 强化数据目录迁移、SQLite/state 一致性、备份、恢复、流式中间结果与异常退出保护；
- 多轮稳定性打磨：会话渲染、数据持久化与多角色场景下的边界行为进一步收敛。

使用远程模型、联网搜索或远程 MCP 服务时，请求会发送到对应服务商。请根据服务商的隐私政策管理敏感内容。

## 质量与交付

- 核心运行时持续模块化，聊天渲染、流式处理、工具结果与审批决策各组件职责清晰；
- 发布前完成系统化验证：自动化测试全量通过、真实 SQLite 通道回归、四视口界面冒烟测试与 MCP 端到端验收；
