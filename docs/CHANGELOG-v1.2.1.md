# 糖包 v1.2.1

> 本地优先、私密可控的 AI 工作空间。

v1.2.1 迎来了桌面宠物：一只常驻桌面的精灵伙伴，会跟随糖码的运行状态做出反应；同时完成一轮覆盖全文检索、MCP 审批记忆、快捷键自定义、输入短语库与糖馆编辑体验的日常打磨；糖码的任务执行获得一轮底层提速，并新增执行耗时画像帮助定位瓶颈；底层代码与发布流程也完成了清理加固。

## 重点更新

### 糖码执行提速

糖码的任务执行完成一轮底层优化：同样的任务，步骤更少、每步更快、出字更早。

- **并行执行**：同一轮里的多个只读操作（读文件、搜索代码、浏览目录等）并发执行，不再逐个排队；
- **更快出字**：发出任务后更快看到首个响应——外部工具清单与技能扫描改为后台进行，不再阻塞请求；超大的项目记忆文件会自动精简后注入；
- **上下文瘦身**：读取大文件时自动按需截断并支持分段续读，避免超大文件拖慢后续每一步；
- **更省的开销**：事件记录与上下文计算改为增量与批量处理，长回答不再产生大量零散写入；外部工具清单保持稳定排序，模型供应商的前缀缓存得以命中，重复上下文不再全价重算；
- **执行耗时画像**：用量统计新增「首字延迟」；任务运行记录提供分段耗时（模型调用、工具执行、审批等待、记录写入）与连接重试次数，时间花在哪里一目了然。

### 桌面宠物

全新的桌宠模块：一只透明置顶的精灵小窗常驻桌面，不占据任务栏，也不打扰正常操作。

- 九种动作状态：待机、左右走动、挥手、跳跃、失败、等待、走动与回顾，均为手绘精灵帧动画；
- 与糖码联动：任务运行、工具调用、等待审批与运行失败时，桌宠会做出对应动作并以气泡提示关键状态；
- 两种位置模式，随时切换：
  - **固定位置**——拖到哪放到哪，位置自动记忆，重启后保持；
  - **自由漫游**——在全屏范围内散步，会水平走动、跳跃换行，走向与动作实时匹配；悬停或拖动时自动暂停；
- 缩放范围 0.4–2.5，窗口随缩放自动扩展，画面始终完整；
- 点击穿透：鼠标不在桌宠上时直接操作下层应用，悬停本体即可互动、拖拽与打开右键菜单（换桌宠、复位位置、置顶、隐藏）；
- 自定义导入：选择一个包含精灵图（webp / png / jpg，文件名任意）的文件夹即可，格子规格可在 meta.json 中自定义，行尾空白帧自动忽略，动画不会闪烁；
- 设置 → 桌宠：所有桌宠以画廊形式预览与选择（首帧静态图 + 名称，点击切换），支持大小调节、位置复位与保持置顶；画廊中导入的桌宠可随时移除——悬停卡片出现移除按钮，确认后连同素材一并删除，删除正在使用的桌宠会自动切回内置伙伴（内置桌宠不可移除）；
- 托盘菜单与顶栏爪印按钮均可快速显示/隐藏；界面支持中英文。

### 快捷键自定义

设置 → 帮助新增快捷键卡：应用内与全局快捷键均支持点击录入自定义组合键，自动检测冲突、一键恢复默认，帮助面板的键位清单实时跟随当前设置；同时修复了部分安装版本中自定义快捷键不生效的问题。

### MCP 审批记忆

MCP 工具的审批弹窗新增两个选项：

- **本会话不再询问**：本次运行内同一工具不再重复审批；
- **永久允许此工具**：写入全局授权规则，后续调用自动放行。

设置 → 提示词新增「已授权工具」清单，可随时查看与撤销；同时修复了此前 MCP 工具调用未按默认进入审批流程的问题，以及旧版本中点过「总是允许」的授权规则失效、导致重复弹窗的问题。

## 检索与输入效率

- 本地全文检索升级至 SQLite FTS5：会话内容检索显著提速，短查询与通配符语法保持兼容；
- 输入框新增快捷短语库：常用提示词一键插入；短语弹层向上展开并限高滚动，不再遮挡或超出窗口。

## 糖馆

- 修复角色编辑器的输入焦点被界面重建抢走的问题：新建与编辑角色时不再需要反复点击输入框；
- 角色卡导出：单张角色卡可导出为标准 JSON；新增「导出全部」将整库打包为合集文件，可随时重新导入，头像与世界书完整保留，方便备份与分享。

## 界面与体验

- 设置 → 外观新增界面语言切换（中文 / English），核心界面完成中英双语覆盖；
- 快捷短语、桌宠等新增界面元素与整体中性风格保持一致，四视口布局均已回归验证；
- 糖绘生图修复：下拉所选模型即实际调用模型，显示与调用保持一致。

## 数据、隐私与安全

- 桌宠与角色卡等新增数据均保存在设备本地；导入的桌宠素材仅存本机，请使用可自由分发的素材；
- Skills 默认阻断网络出站，只有明确允许的配置才开放网络；
- 工具调用、文件写入、命令执行和 MCP 调用沿用统一权限与审批边界，MCP 审批结果可按会话或全局持久化。

## 质量与交付

- 完成底层代码清理：移除历史遗留的重复实现，关键行为以回归测试固化；
- 发布前完成系统化验证：自动化测试全量通过、真实 SQLite 通道回归、四视口界面冒烟测试，并以自动校验脚本核对安装包与源码一致性，防止旧包误发。
