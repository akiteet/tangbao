# 糖包 v1.1.0 发布说明

> 发布日：2026-08-08 ｜ 仓库：github.com/akiteet/tangbao

## 糖码 · 编码助手

- **Plan 模式**：先只读探索产出任务清单 → 首次写操作弹「计划待批准」→ 批准后同 run 自动执行；不确定时主动提问（选项 + 自定义填空，单选/多选）。
- **权限体系**：6 档权限模式（plan / default / acceptEdits / auto / bypass / sandbox）+ 项目规则（总是允许/拒绝/命令白名单），拒绝时给替代建议。
- **运行历史**：检查点精确恢复 + 自动无感续段，历史全文查看与检索。
- **上下文管理**：压缩异步化 + 预算统一，首次压缩同步，计划/错误/变更不丢。
- **多根工作区**：项目可挂多文件夹，任务范围三档（单根/多根/全部）。
- **技能系统**：标准 `SKILL.md` 技能机制，设置面板导入/启停/信任/移动/隔离区恢复；修复项目级 Skill 跨盘卸载/恢复。
- **本地安全评测**：23 项白名单任务 + 隔离 fixture，一键批量跑安全基线。
- 约 36 项系统性 Bug 修复。
