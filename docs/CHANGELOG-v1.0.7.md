# 糖包 v1.0.7 发布说明

> 发布日：2026-08-04 ｜ 仓库：github.com/akiteet/tangbao

## 本次版本主要更新（大版本重构）

### 1. 分层架构重构
代码按 **renderer（视图）/ application（服务）/ core（模型·错误·Schema）/ infrastructure（存储·网关·密钥·Agent 运行时）/ main / preload** 六层重组，逻辑边界清晰，为后续迭代打基础。

### 2. 数据存储全面升级（SQLite + 文件仓）
- 引入 **better-sqlite3**（14 张表），取代「大一统 App.state」全量序列化；
- 文件仓独立存放图片/文档/缩略图/导出/日志，**图片从 Base64 改为文件存储**，大图不再卡顿；
- **一次性迁移器**：启动时自动把旧数据安全迁入 SQLite，**保留只读备份**（`state.v1.backup.json`，升级轮转保留 3 份），旧文件不删除直到新版本稳定；
- **SQLite 成为主数据源**：读优先 SQLite + 写穿同步，state.json 双写兜底，切换失败自动回退，全程不丢数据；
- **Schema 版本化迁移框架**：后续升级改表结构有据可依；
- 启动 **完整性自检**（integrity_check）+ 文件仓孤儿文件自动清理；
- 新增「**完整数据备份**」导出/导入（含全部对话、图片、项目、会话线程，经系统文件对话框）。

### 3. 统一模型能力
- 模型能力判定集中到单一模块（深度思考/联网搜索/视觉/工具调用），不再散落正则；
- 账户模型新增「**能力预设**」（工具+视觉 / 工具+文本 / 仅视觉 / 纯文本），发送前校验：**不给不支持工具的模型发工具定义、不把图片编辑请求发给不支持视觉的模型**，报错改为可行动提示；
- **7 类统一错误**（鉴权失败 / 限流 / 模型不可用 / 上下文超限 / 能力不支持 / 网络错误 / 供应商错误），用户看到的是可行动信息而非供应商原始 JSON。

### 4. IPC 服务化
渲染层不再直接触碰 Electron 通道，统一收敛为 `App.services` 领域服务（system/secrets/fs/gateway/shell/float）。

### 5. 问题修复
- 助手回复**偶发「输出一堆后突然消失」**（流式渲染竞态，已修复）；
- **强制嵌入的外部站点 403 打不开**（如 libhd.com）：子窗口伪装 Chrome UA + 加载失败诊断页 + 一键「在系统浏览器打开」兜底；
- 设置面板文案修正：API Key 说明、能力预设说明补全。

## 升级提示
- 首次启动自动迁移旧数据到 SQLite 并保留只读备份；迁移成功前旧数据原样保留；
- **API Key 保存在本机系统安全存储**（Windows DPAPI / macOS Keychain / Linux libsecret），不随导出文件迁移，换设备后需在「账户」中重新填写；
- 若迁移后发现问题，可删除 `tangbao-data/tangbao.db` 回退到 state.json 数据（备份仍在）。
